# CLI File Manager

A command-line file manager written in **C++** for navigating and interacting with the filesystem.

The project is being developed progressively, starting with basic filesystem navigation and building toward a more complete terminal-based file manager.

## Features

### Navigation

* `ls` — List files and directories
* `pwd` — Show the current directory
* `cd <directory>` — Enter a directory
* `back` — Go to the parent directory

### File and Directory Operations

* `mkdir <name>` — Create a directory
* `touch <name>` — Create an empty file
* `rename <old> <new>` — Rename a file or directory
* `cp <source> <destination>` — Copy a file
* `mv <source> <destination>` — Move a file or directory
* `rm <name>` — Remove a file or empty directory

### Other

* `help` — Display available commands
* `q` — Quit the file manager
* Basic error handling for invalid operations

## Building

Clone the repository:

```bash
git clone https://github.com/SarinaTari/cli-file-manager.git
cd cli-file-manager
```

Create the build directory:

```bash
cmake -S . -B build
```

Build the project:

```bash
cmake --build build
```

## Running

From the project root:

```bash
./build/filemanager
```

You should see:

```text
CLI File Manager

Current directory: "/path/to/cli-file-manager"
>
```

You can then use commands such as:

```text
ls
pwd
mkdir test
cd test
touch hello.txt
rename hello.txt hello2.txt
cp hello2.txt backup.txt
mv backup.txt ..
back
rm test
help
q
```
